# Chelsha Car Rental — Network Design

A network design and simulation project for **Chelsha**, a small vehicle rental company transitioning from a paper-based system to an online business environment.

## 📌 Project Overview

The project involved analysing the company's networking requirements and designing a secure, reliable and cost-effective network infrastructure to support employees, customers and business services.

The network was designed to support:

* Employee workstations
* Wired and wireless connectivity
* Network printers
* Database and application services
* Website hosting
* Email communication
* File transfer
* Customer Wi-Fi access

## 🌐 Network Design

Three alternative network solutions were designed and evaluated:

### Solution 1

* Two LANs
* 6 employee PCs
* Server and printer
* Wireless access point
* Copper cabling

### Solution 2

* Two LANs
* 8 devices
* Server and printer
* Fiber-optic cabling

### Solution 3

* Two LANs
* 6 PCs and 2 laptops
* Two servers for separate email and website services
* Printer and wireless access point
* Combination of copper and fiber cabling

The alternatives were compared based on **cost, performance, scalability, security and implementation requirements**.

## 🧪 Testing

The final network was tested using **Cisco Packet Tracer** for:

* LAN-to-LAN connectivity
* PC-to-PC communication
* PC-to-printer connectivity
* Server connectivity
* Wired-to-wireless communication
* Website and domain functionality
* Email transfer
* FTP file transfer

All documented connectivity tests were successful.
